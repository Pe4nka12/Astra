# Astra — адаптивный ИИ-чат

Astra — самостоятельное браузерное веб-приложение на HTML, CSS и JavaScript. Для запуска не нужны npm, сборщик или сторонние библиотеки.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте терминал в этой папке.
3. Запустите локальный статический сервер:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000` в браузере.

Можно использовать любой другой статический сервер. Не рекомендуется открывать `index.html` напрямую через `file://`: некоторые браузеры ограничивают работу локального хранилища и запросов в таком режиме.

## Где указать API

Откройте **Настройки → Подключение**:

- **Основной URL API** — базовый адрес вашего API-сервера. Вставьте адрес, выданный вашим провайдером.
- **Путь chat endpoint** — путь метода чата. Для режима OpenAI-compatible по умолчанию указан `/v1/chat/completions`; замените его, если у вашего сервиса другой путь.
- **Модель** — точное имя модели, доступное в вашем API.
- **API-ключ** — ваш ключ. По умолчанию он хранится только в памяти открытой вкладки. Флажок «Сохранять ключ на этом устройстве» записывает его в localStorage браузера без шифрования.
- **Заголовок авторизации / Префикс ключа** — по умолчанию `Authorization` и `Bearer`. Поменяйте их, если ваш сервис ожидает другой заголовок или формат.

Astra не содержит настоящего ключа, адреса провайдера или заранее выбранной модели. Значение URL, имя модели и ключ нужно получить у своего API-провайдера.

### Генерация изображений

В разделе **Настройки → Подключение** укажите **полный URL генерации изображений** и при необходимости отдельное имя image-модели. Для этого запроса используется тот же API-ключ и настройки заголовка авторизации.

Встроенный формат по умолчанию отправляет JSON с полями `prompt`, `size`, `n` и `model`, а в ответе ищет `data[0].url` или `data[0].b64_json`. Если ваш сервис использует другой формат, откройте **Настройки → Дополнительно** и измените:

- **JSON-шаблон запроса изображений** — доступные подстановки `{{prompt}}`, `{{size}}`, `{{n}}`, `{{model}}`;
- **Путь к URL или base64 изображения** — путь через точку, например `data.0.url` или `result.image`.

Поддержка генерации и возвращаемый формат зависят от конкретного сервиса.

## Формат API чата

По умолчанию Astra использует не потоковый запрос в стиле OpenAI Chat Completions:

- отправляет `model`, `messages`, `temperature`, `max_tokens`, `top_p`, `frequency_penalty`, `presence_penalty`;
- читает текст по пути `choices.0.message.content`.

Для совместимого сервиса достаточно указать основной URL, путь endpoint, модель и ключ. Если API отличается, выберите **Настройки → Дополнительно → Пользовательский JSON-шаблон**.

В шаблоне запроса поддерживаются подстановки:

- `{{model}}`
- `{{messages}}`
- `{{temperature}}`
- `{{max_tokens}}`
- `{{top_p}}`
- `{{frequency_penalty}}`
- `{{presence_penalty}}`
- `{{file_ids}}`

Подстановки в виде отдельного значения JSON заменяются значением соответствующего типа: массивы остаются массивами, числа — числами. В поле **Путь к тексту ответа** укажите путь к тексту в JSON-ответе. Например, `choices.0.message.content`, `output_text` или `result.answer`.

Если API использует другие HTTP-методы, особую авторизацию, multipart-структуру запроса чата или нестандартную логику ответа, адаптируйте функции `callChatApi`, `authHeaders` или `normalizeAssistantContent` в `app.js` под документацию провайдера.

## Файлы и изображения в чате

- Текстовые форматы (TXT, MD, CSV, JSON, XML, YAML, HTML, CSS, JS/TS, Python и распространённые исходники) читаются браузером и добавляются к содержимому сообщения. Ограничение встроенного чтения — 1 МБ на файл.
- Изображения отправляются как data URL внутри сообщения. Ограничение — 8 МБ на изображение. Модель и API должны поддерживать изображения/vision.
- PDF, DOCX, XLSX и другие бинарные форматы не имеют универсального формата передачи в Chat Completions. Для них можно настроить **URL загрузки файлов** и **Путь к ID файла в ответе**. Astra отправит файл как `multipart/form-data` с полем `file`, затем передаст полученные ID в `{{file_ids}}` пользовательского JSON-шаблона. Дальнейшую передачу и использование ID нужно настроить по документации вашего API.
- Не более 8 файлов за одно сообщение.

Наличие кнопки прикрепления не означает, что провайдер поддерживает конкретный формат: обработка зависит от endpoint и модели.

## Хранение и приватность

- История чатов и настройки сохраняются в localStorage текущего браузера и не синхронизируются между устройствами.
- API-ключ не сохраняется, если не включить соответствующий флажок. Если включить — ключ будет храниться в localStorage без шифрования.
- Секретный чат не добавляется в историю, не записывается в localStorage и не использует поле пользовательской памяти. После выхода из него переписка удаляется из памяти вкладки. Сообщения секретного чата всё равно отправляются выбранному API-провайдеру для получения ответа.
- Экспорт чатов не включает API-ключ. Экспортируются только сохранённые обычные чаты.

## Важные ограничения безопасности

Это клиентское приложение: ключ используется в браузере и может быть виден человеку, имеющему доступ к устройству, вкладке, DevTools или сетевым журналам. Хранение ключа в localStorage не является защищённым хранилищем. Для публичного или производственного размещения рекомендуется добавить собственный серверный proxy/backend, хранить ключ на сервере и настроить CORS/проверку доступа там.

Провайдер должен разрешать CORS-запросы с origin, на котором запущена Astra. Ошибки сети, CORS и несовместимости API отображаются в **Настройки → Подключение → Диагностика**.

## Возможности интерфейса

- адаптивная раскладка для мобильных устройств и компьютеров;
- создание, переименование и удаление чатов;
- редактирование пользовательского сообщения с повторной генерацией;
- повторная генерация ответа и остановка активного запроса;
- светлая, тёмная и системная темы;
- системный промт и подключаемая пользовательская память;
- генерация изображений через отдельный endpoint;
- Markdown-отображение заголовков, списков, таблиц, цитат, ссылок и блоков кода с кнопкой копирования.

Подсветка синтаксиса кода и потоковая генерация ответов не включены. Приложение не заявляет универсальную совместимость с любым API: формат запроса, набор параметров, файловые возможности, vision и генерация изображений зависят от сервиса и модели.
