Формат API

Если ваш API не совместим с Chat Completions, настройте шаблон тела запроса и путь к ответу.

Подстановки: {{model}}, {{messages}}, {{temperature}}, {{max_tokens}}, {{top_p}}, {{frequency_penalty}}, {{presence_penalty}}, {{file_ids}}. Поля-подстановки заменяются значениями соответствующего типа.
Путь через точку к полю в JSON-ответе. Для массива используйте индекс, например data.0.text.

Формат генерации изображений

Шаблон независим от чата. Подстановки: {{prompt}}, {{size}}, {{n}}, {{model}}.

Ожидается URL, data URL или base64-строка по заданному пути. Встроенный резервный разбор понимает data[0].url и data[0].b64_json.

Файлы

Обработка зависит от формата API. Встроенный адаптер умеет добавлять текстовые файлы к сообщению и передавать изображения как data URL, если модель поддерживает vision.

Загрузка файлов — нестандартная функция. Если заполнить URL, Astra отправит файл как multipart/form-data, извлечёт ID по указанному пути и добавит список ID в {{file_ids}} пользовательского JSON-шаблона. Для этого используйте режим «Пользовательский JSON-шаблон» и настройте дальнейшую передачу ID по документации вашего сервиса. Без URL загрузки PDF/DOCX и другие бинарные форматы не передаются встроенным адаптером.

Локальные данные

История чатов и настройки хранятся в браузере на этом устройстве.

Сохранённые данные не синхронизируются между устройствами. Секретные чаты и их сообщения не экспортируются.
